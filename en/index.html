Download the ja-netfilter agent

ja-netfilter is a local Java agent that lets your IDE accept a custom license code. It must be installed on your machine.

💡 After downloading, unzip it to any folder (suggested: ~/ja-netfilter/) and remember the path — you will need it in the next step.

Method 1: GUI (Recommended)

  1. Open any JetBrains IDE
  2. Menu bar → Help → Edit Custom VM Options...
  3. Append one line to the end of the opened file (replace the path with your actual unzip path):
-javaagent:/Users/your-username/ja-netfilter/ja-netfilter.jar

Method 2: Edit the file manually

# macOS/Linux users, run in Terminal: echo -e '\n-javaagent:/your-path/ja-netfilter.jar' >> "$HOME/Library/Application Support/JetBrains/ProductName202x.x/ProductName.vmoptions"
# Windows users, run in PowerShell: Add-Content "$env:APPDATA\JetBrains\ProductName202x.x\ProductName.vmoptions" "`n-javaagent:C:\your-path\ja-netfilter.jar"
⚠️ Common mistakes:
  • The path must be your actual unzip path — do not copy it verbatim
  • If the IDE fails to start, the path is wrong — delete the vmoptions file and start over
  • Fully quit and restart the IDE after editing
3
Generate a license code & activate the IDE
🎯 Last step:
Open the IDE (make sure Step 2 is done) → the activation dialog appears → choose Activation code → paste → click Activate.
