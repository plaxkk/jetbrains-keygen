## О проекте

Статический сайт для изучения RSA-подписей, Java-агентов и механизма пользовательских кодов активации. Коды создаются локально в браузере; сайт размещён на Vercel.

- **ja-netfilter.zip** — локальный Java-агент, с помощью которого IDE распознаёт пользовательские коды.
- **index.html** — китайская версия и общий исходный шаблон страницы.
- **ru/index.html** — русская версия с готовым HTML для поисковых систем.

Проект не связан с JetBrains и не предоставляет официальных лицензий.

## Продукты

В интерфейсе доступны 14 продуктов:

IntelliJ IDEA, PhpStorm, DataGrip, RubyMine, WebStorm, Rider, CLion, PyCharm, GoLand, DataSpell, dotMemory, Aqua, RustRover, AppCode.

- Если ничего не выбрано, создаётся код для всего набора.
- Если выбраны отдельные продукты, код создаётся только для них.

Исходный проект также заявляет поддержку платных плагинов и автоматическое распознавание кода установленными IDE. Совместимость с конкретными версиями необходимо проверять отдельно; после обновлений инструмент может перестать работать.

## Настройка в 3 шага

### Шаг 1. Скачайте ja-netfilter

ja-netfilter необходимо установить на вашем компьютере.

1. Скачайте [ja-netfilter.zip](ja-netfilter.zip), около 311 КБ. Архив также доступен на странице инструмента.
2. Распакуйте архив, например в `~/ja-netfilter/`, и запомните фактический путь.

### Шаг 2. Настройте VM Options

**Способ 1: через меню IDE (рекомендуется)**

1. Откройте JetBrains IDE.
2. Выберите **Help** → **Edit Custom VM Options...**.
3. Добавьте строку в конец файла, заменив путь на фактический:

```text
-javaagent:/path/to/ja-netfilter.jar
```

Пример для macOS:

```text
-javaagent:/Users/your-username/ja-netfilter/ja-netfilter.jar
```

**Способ 2: редактирование файла вручную**

Пример команды для терминала macOS. Замените путь и название продукта на значения из вашей системы:

```bash
echo -e '\n-javaagent:/your-path/ja-netfilter.jar' >> "$HOME/Library/Application Support/JetBrains/ProductName202x.x/ProductName.vmoptions"
```

Пример для Windows PowerShell:

```powershell
Add-Content "$env:APPDATA\JetBrains\ProductName202x.x\ProductName.vmoptions" "`n-javaagent:C:\your-path\ja-netfilter.jar"
```

Типичные расположения файла:

- macOS: `~/Library/Application Support/JetBrains/ProductName202x.x/ProductName.vmoptions`
- Windows: `%APPDATA%\JetBrains\ProductName202x.x\ProductName.vmoptions`

В Linux не используйте путь из примера для macOS. Откройте нужный файл через **Edit Custom VM Options...**.

Перед перезапуском проверьте фактический путь к агенту. Если IDE перестала запускаться, удалите добавленную строку, сохранив остальные настройки. После изменений полностью закройте и заново запустите IDE.

### Шаг 3. Создайте код

1. Откройте [русскую версию](https://jetbrains-keygen.kkplayit.online/ru/).
2. Укажите имя пользователя и срок действия. Значения по умолчанию: `User` и `2099-12-31`. Имя отображается в окне About.
3. Выберите продукты. Чтобы создать код для всего набора, снимите все отметки.
4. Нажмите **✨ Создать код активации**, затем скопируйте результат.
5. Откройте IDE после настройки на шаге 2. В окне активации выберите **Activation code**, вставьте код и нажмите **Activate**.

Если вы используете Claude Code, Cursor, Hermes Agent или Copilot CLI, передайте ассистенту этот запрос. Проверяйте предложенные действия перед выполнением.

```text

Адрес инструмента: https://jetbrains-keygen.kkplayit.online/ru/

Сначала уточните, какие продукты мне нужны:
1. Для одного продукта выберите только его в списке на странице и создайте код.
2. Для всего набора снимите все отметки и создайте код для всех продуктов.
Порядок действий: скачайте ja-netfilter.zip со страницы инструмента и распакуйте архив; найдите файл vmoptions IDE; добавьте в конец строку -javaagent:<путь-к-агенту>/ja-netfilter.jar; перезапустите IDE; создайте код на сайте и вставьте его в поле Activation code окна активации.
Путь к файлу vmoptions можно узнать через меню Help → Edit Custom VM Options... в IDE.
Если я не указал продукт, сначала спросите, нужен ли один продукт или весь набор. Не выбирайте продукт за меня. Используйте имя User, если я не указал другое.
```

## Поддержка переводов

Редактируйте общий шаблон в `index.html`, а русские тексты — в `locales/ru.json`. Динамические уведомления и запросы к ИИ находятся в `index.html`. Затем выполните:

```bash
python3 scripts/build-locales.py
```

Команда создаёт статические страницы `/en/`, `/ko/`, `/ru/` и обновляет `sitemap.xml`. Не редактируйте сгенерированные страницы напрямую; добавляйте их в коммит вместе с исходными файлами перед публикацией.
