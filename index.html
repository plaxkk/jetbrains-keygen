方法 1：图形界面（推荐）

  1. 打开任意 JetBrains IDE
  2. 菜单栏 → Help → Edit Custom VM Options...
  3. 在弹出的文件末尾添加一行（把路径换成你的解压路径）：
-javaagent:/Users/你的用户名/ja-netfilter/ja-netfilter.jar

方法 2：手动编辑文件

# macOS/Linux 用户，终端执行： echo -e '\n-javaagent:/你的路径/ja-netfilter.jar' >> "$HOME/Library/Application Support/JetBrains/产品名202x.x/产品名.vmoptions"
# Windows 用户，PowerShell 执行： Add-Content "$env:APPDATA\JetBrains\产品名202x.x\产品名.vmoptions" "`n-javaagent:C:\你的路径\ja-netfilter.jar"
⚠️ 常见错误：
  • 路径必须用你实际的解压路径，不能直接照抄
  • 如果 IDE 打不开，说明路径填错了——删掉 vmoptions 文件重来
  • 修改完后必须完全退出 IDE 再重新打开
3
生成激活码 & 激活 IDE
🎯 最后一步：
打开 IDE（确保已完成步骤 2）→ 出现激活窗口 → 选择 Activation code → 粘贴 → 点 Activate。
