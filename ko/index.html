ja-netfilter 에이전트 다운로드

ja-netfilter는 IDE가 사용자 지정 라이선스 코드를 인식하도록 하는 로컬 Java 에이전트입니다. 사용 중인 컴퓨터에 설치해야 합니다.

💡 다운로드한 파일을 원하는 폴더에 압축 해제하세요. 권장 경로는 ~/ja-netfilter/입니다. 다음 단계에서 사용할 수 있도록 경로를 확인해 두세요.
2
IDE의 VM Options 설정

🪟 Windows

  2. 메뉴에서 Help → Edit Custom VM Options...를 선택합니다.
  3. 열린 파일의 마지막 줄에 아래 내용을 추가합니다. 경로는 실제 압축 해제 위치로 바꿔 주세요.

  2. 메뉴에서 Help → Edit Custom VM Options...를 선택합니다.

방법 1: IDE 메뉴에서 설정 (권장)

  1. JetBrains IDE를 실행합니다.
  2. 메뉴에서 Help → Edit Custom VM Options...를 선택합니다.
  3. 열린 파일의 마지막 줄에 아래 내용을 추가합니다. 경로는 실제 압축 해제 위치로 바꿔 주세요.
-javaagent:/Users/your-username/ja-netfilter/ja-netfilter.jar

방법 2: 파일 직접 편집

# macOS: 터미널에서 실행 (실제 경로와 제품명으로 변경) echo -e '\n-javaagent:/your-path/ja-netfilter.jar' >> "$HOME/Library/Application Support/JetBrains/ProductName202x.x/ProductName.vmoptions"
# Windows: PowerShell에서 실행 (실제 경로와 제품명으로 변경) Add-Content "$env:APPDATA\JetBrains\ProductName202x.x\ProductName.vmoptions" "`n-javaagent:C:\your-path\ja-netfilter.jar"
⚠️ 확인 사항
  • 예제 경로를 그대로 사용하지 말고 실제 압축 해제 경로로 바꿔 주세요.
  • 설정 후 IDE가 실행되지 않으면 추가한 javaagent 경로를 확인하고, 해당 줄을 제거해 원래 설정으로 복구하세요.
  • 변경 후에는 IDE를 완전히 종료한 뒤 다시 실행해야 합니다.

보증 없음: 이 도구는 있는 그대로 제공됩니다. 상품성이나 특정 목적에 대한 적합성을 포함해 어떠한 명시적·묵시적 보증도 제공하지 않습니다. JetBrains 제품이 업데이트되면 도구가 작동하지 않을 수 있습니다.
